Anteater Poker Game (EECS 22L)

Uses: C++, Git (Version control and collaboration), TCP/IP, GTK 3.0, Linux command line

Description: For five weeks I was part of a team of seven that worked on building a poker game that would allow players (human- or computer-controlled) to connect to a server and play a modified version of Texas Hold'em that features our school's mascot. I was primarily responsible for the data structures and communcation protocols, as well as the basic structure of the user display.
