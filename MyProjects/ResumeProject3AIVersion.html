Photo and Video Editor

Throughout the course I added to the provided code for loading and saving PPM images to create a photo editor. I also created a video editor for the final project of the course through a similar process.

Anteater Poker Game (EECS 22L)

C++ · TCP/IP · GTK 3.0 · Git · Linux command line

For five weeks I was part of a team of seven that built a poker game in which human- or computer-controlled players could connect to a server and play a modified version of Texas Hold'em featuring our school's mascot. I was primarily responsible for the data structures and communication protocols, as well as the basic structure of the user display.

Single-Cycle RISC-V Processor (EECS 31L)

Verilog · Testbenches · Digital logic

Throughout the course I built and integrated modules in Verilog to create a single-cycle RISC-V processor. I also analyzed and debugged the design using testbench code.

Source code for these and other college course projects is not posted publicly because I have not received permission to release it.
